# # Lab 8 - Implementación Full Stack con React y Apollo Client

## Descripción
En este laboratorio se implementó una aplicación **Full Stack** utilizando React en el frontend y GraphQL en el backend, conectando ambos mediante **Apollo Client** para consumir consultas y mutations.

---

## Estructura del proyecto

- **fe_test/** → Frontend en React
- **be_grahpql/** → Backend GraphQL con MongoDB
- **Apollo Client** → Cliente para consumo de GraphQL
- **Apollo Server** → API GraphQL

---

## Funcionalidades

- Consumo de queries desde React
- Ejecución de mutations desde el frontend
- Visualización de empleados y datos desde MongoDB
- Comunicación en tiempo real con el backend GraphQL
